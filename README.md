# 글결 — AI 블로그 콘텐츠 스튜디오

업체 정보로 네이버·티스토리용 초안을 생성하는 React 앱입니다. OpenAI Responses API는 Node 서버에서만 호출합니다.

## 실행 (Node 22.9 이상)

1. `npm ci`
2. `.env.example`을 `.env`로 복사합니다.
3. `.env`의 `OPENAI_API_KEY`에 본인 키를, `APP_ACCESS_CODE`에 길고 추측하기 어려운 이용 암호를 설정합니다. 키와 암호를 GitHub에 올리지 마세요. `VITE_` 접두사도 사용하지 마세요.
4. `npm start`
5. `http://localhost:3000`에서 이용 암호와 업체 정보를 입력하고 생성합니다.

API 이용 비용은 API 계정으로 발생합니다. 실제 키로 성공 응답을 확인하기 전까지 실서비스 연결 검증은 완료된 것이 아닙니다.

## GitHub에서 이어서 쓰는 경우

GitHub Codespaces 같은 Node 실행 환경에서는 위 명령을 터미널에서 실행할 수 있습니다. 3000번 포트는 비공개로 유지하고, `.env`는 그 실행 환경에서만 만드세요. GitHub 저장소 자체와 GitHub Pages는 이 Node 서버를 실행하지 않습니다. 기존 앱 주소에 반영하려면 해당 호스팅이 Node 서버 실행을 지원해야 합니다.

## 범위 및 제한

- 네이버는 일반 텍스트, 티스토리는 마크다운 소제목을 요청합니다.
- 사진 처리, 웹 검색, 자동 게시, 회원별 과금은 아직 없습니다.
- 개인정보나 업체 기밀은 입력하지 마세요. 생성 시 입력 내용이 OpenAI로 전송됩니다. API 요청은 `store: false`입니다.
- 이용 암호는 브라우저 메모리에서만 사용합니다. 서버가 설정되지 않으면 AI 호출을 차단합니다.
- 프로세스당 시간당 최대 20회, 동시 1회 호출 제한이 있습니다. 재시작·다중 서버에서 공유되지 않으므로 상용 서비스에는 회원 인증과 영속적인 사용량 제한이 필요합니다.
- 현재 `npm start`는 Vite 개발 미들웨어를 사용합니다. 비공개 개발·검증용이며, 공개 상용 배포 전 프로덕션 서버 구성이 필요합니다.
- 모델이 생성한 정보는 사실 검증되지 않았습니다. 게시 전에 확인하세요. 검색 순위나 AI 인용을 보장하지 않습니다.

검사: `npm test`, `npm run build`

## 사진 번호 및 삽입 안내 (첫 버전)

사진 최대 10장(JPG/PNG/WebP, 장당 10MB)을 브라우저에서 선택합니다. 사진에 설명을 입력하고 순서를 바꿀 수 있으며 번호는 삭제·정렬 후에도 다시 매기지 않습니다. 번호와 설명이 붙은 파일명으로 개별 다운로드할 수 있습니다.

생성 본문 문단 사이에 선택 순서대로 사진 안내를 분산 배치합니다. AI 사진 분석 또는 내용별 최적 위치 판단은 아직 없습니다. 사진과 설명은 OpenAI로 전송하지 않습니다. 본문 복사에는 사진 삽입 안내와 파일명이 포함되며 이미지 자체는 포함되지 않습니다. 블로그에서 직접 사진을 업로드한 뒤 안내 문구를 지워야 합니다. 완료 체크는 사용자의 작업 메모이며 실제 업로드 확인이 아닙니다.

새로고침·창 닫기 시 사진과 작성 내용은 사라집니다. 중요 사진 원본과 생성 글은 별도로 보관하세요. 이 버전에는 HTML 서식 복사 및 미넴 디자인 적용이 포함되지 않습니다.
